# TrackerLink
Track And Get Victim Device Information
> INSTALL SCRIPT
```
gitclone https://github.com/xvlisrinze/TrackerLink.git
```
> Using Java Script
> Install Before Using
```
apt install nodejs
```
> Install Depence Modules
```
npm i express chalk localtunnel
```
